Privacy

Effective date: 2026-10-12

Iris for Alexa+ is a read-only MCP server from elghaly (Wyndham Heaven). It checks crypto messages, links, and public Solana transactions for known scam patterns. It is not made by Amazon.

What the server receives

We receive what a tool call contains: the message or description you ask about, a link or domain, a public Solana transaction signature, or the name of a topic or device. There are no accounts, no sign-in, and no cookies set by Iris.

What it does with it

  • It checks the input in memory, returns an answer, and keeps nothing. Tool inputs are not written to a database or a file.
  • When something fails, the server may write a short log line with just the error kind (for example tool error name=Error). It does not log the text you sent.
  • A 12- or 24-word seed phrase is refused before any rule reads it. It is not sent to the RPC, stored, or logged.
  • Links are never opened or fetched. They are checked as text, nothing more.
  • To explain a transaction, the server makes one request to a public Solana RPC with the signature you gave. That signature is already public on the chain.

What it never does

It never asks for or accepts a private key or seed phrase, never connects to a wallet, never signs or sends anything, and never sells or shares what you send.

Hosting

If you run this server on a hosting service, that service may keep its own access logs (time, client IP, path) under its privacy policy. If you run it on your own machine, nothing leaves your machine except the one RPC call above.

The simulated page

The page at /sim is a simulated Alexa+ page, not a real Alexa device. It has no Amazon or Alexa logos or sounds. Hold-to-talk uses your browser's speech recognition; what your browser does with audio is controlled by your browser, not by Iris.
