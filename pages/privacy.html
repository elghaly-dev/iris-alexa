Privacy

Iris for Alexa+ is a read-only MCP server made by elghaly. It checks crypto messages, links and public Solana transactions for known scam patterns. Last updated 2026-10-11.

What the server receives

Only what a tool call contains: the message or description you ask about, a link or domain, a public Solana transaction signature, or the name of a topic or device. There are no accounts, no sign-in and no cookies.

What it does with it

  • It checks the input in memory, answers, and keeps nothing. Tool inputs are not written to a database or a file.
  • The server's own log lines hold only the kind of error, never the text you sent.
  • A 12- or 24-word seed phrase is refused before any rule reads it, and it is never stored or logged.
  • Links are never opened or fetched. They are checked as text.
  • To explain a transaction, the server makes one request to a public Solana RPC with the signature you gave. A signature is already public on the chain.

What it never does

It never asks for or accepts a private key or seed phrase, never connects to a wallet, never signs or sends anything, and never sells or shares what you send.

Hosting

When this server runs on a hosting service, that service may keep standard access logs (such as time, IP address and path) under its own privacy policy. When you run it yourself, nothing leaves your machine except the one RPC call above.

The simulated page

The page at /sim is a simulated Alexa+ page, not a real Alexa device. Its hold-to-talk button uses your browser's own speech recognition; what your browser does with audio is set by your browser.
